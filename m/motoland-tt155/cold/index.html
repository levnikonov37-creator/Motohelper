Motoland TT155 глохнет на холодную

Проверка по шагам для мотора ZS1P60YMJ (155 см³) — с его цифрами. Иди по порядку, от простого к сложному. Частые причины: проблема не в прогреве, не работает обогатитель, подсос воздуха, засор холостого канала.

Цифры ZS1P60YMJ

СвечаD8TC / CR7HSA, зазор 0.6⁠–⁠0.8 мм
Клапаны (на холодную)впуск 0.08 мм на холодном (руководство Kayo, TT160 с мотором ZS1P60YMJ; Thumpstar — 0.003″), выпуск 0.09 мм по руководству Kayo; 0.13 мм (0.005″) по руководству Thumpstar
Масло10W-40, около 1 л (Kayo), 0.95 л (Thumpstar)
Обороты ХХ1400⁠–⁠1600 (1500 ± 100, Kayo)
Компрессия10⁠–⁠12 бар
КарбюраторPZ26 / PE26 / PWK28
Главный жиклёр108⁠–⁠118

Что проверить

  1. После прогрева проблема пропадает?Нет → Проблема не в прогревеСмотри жиклёры: главный 108–118, холостой 38–40. Чистка карбюратора.
  2. Пусковой обогатитель (подсос) работает?Залип → Не работает обогатительПочисти шток, проверь трос и ход рычага.
  3. Обороты холостого плавают вверх-вниз?Да → Подсос воздухаПроверь впускной патрубок и хомуты: брызни WD на стыки на холостых — изменились обороты, значит там.
  4. Клапаны регулировал по регламенту (0.08 мм на холодном (руководство Kayo, TT160 с мотором ZS1P60YMJ; Thumpstar — 0.003″) / 0.09 мм по руководству Kayo; 0.13 мм (0.005″) по руководству Thumpstar)?Да → Засор холостого каналаПродуть холостой жиклёр 38–40, отрегулировать ХХ 1400–1600 (1500 ± 100, Kayo).Давно → Зажаты клапаныРегулировка на холодную: впуск 0.08 мм на холодном (руководство Kayo, TT160 с мотором ZS1P60YMJ; Thumpstar — 0.003″), выпуск 0.09 мм по руководству Kayo; 0.13 мм (0.005″) по руководству Thumpstar.
