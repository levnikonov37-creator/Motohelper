Клапаны на японском DOHC: шайба под толкателем

⏱ 3–5 чсложно5 шагов

Понадобится

  • Щупы
  • Микрометр
  • Набор шайб
  • Динамометрический ключ

Пошагово

  1. Японские моторы держат зазоры долго — проверяй по регламенту (по мануалу км), а не «на всякий случай».
  2. Норма на холодную: впуск по таблице, выпуск по таблице.
  3. Зазор уменьшился — клапан «садится»: шайба нужна тоньше.
  4. Под толкателем шайба маленькая — снимается только с распредвалами, держи её магнитом.
  5. Собирай строго по меткам ГРМ, затяжка крышек постелей по мануалу.
