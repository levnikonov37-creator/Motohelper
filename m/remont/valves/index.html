Регулировка клапанов (винты)

⏱ 1–1.5 чсредне7 шагов

Понадобится

  • Набор щупов
  • Ключ на гайки регулировки
  • Отвёртка/ключ регулировки
  • Свечной ключ

Пошагово

  1. Только на холодном моторе — не раньше чем через 3–4 часа после поездки.
  2. Сними крышки клапанов, выкрути свечу нужной марки — проворачивать будет легче.
  3. Сними заглушку на крышке генератора, поворачивай коленвал по ходу, пока метка «T» не совпадёт с риской.
  4. Убедись, что поршень в ВМТ такта сжатия: оба коромысла имеют люфт. Если нет — ещё один оборот.
  5. Впуск: щуп по таблице должен проходить с лёгким закусыванием. Выпуск: по таблице.
  6. Ослабь контргайку, выставь зазор винтом, держа винт, затяни гайку и перепроверь щупом.
  7. Поставь крышки на новые уплотнения, заверни свечу (момент по таблице).
