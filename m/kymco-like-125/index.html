Частые вопросы

Какое масло заливать в Kymco Like 125?

10W-40 (JASO MB/MA); в редуктор — 80W-90 / SAE 10W-30, объём ≈ 0.9 л; редуктор ≈ 0.15 л. Замена каждые 2 500 км · ≈ 65 моточ.

Какая свеча на Kymco Like 125?

NGK CR7HSA, зазор 0.6–0.7 мм.

Какие зазоры клапанов на Kymco Like 125?

Впуск 0.10 мм, выпуск 0.10 мм, на холодном моторе.

Какой мотор стоит на Kymco Like 125?

Kymco/SYM 125 (GY6-тип) (Kymco Agility 125 / Like 125 · SYM Symphony 125 (4T 125, воздушный)), 125 см³, 9.5 л.с.

Какие слабые места у Kymco Like 125?

Клапаны зажимаются — тяжёлый пуск на горячую, потеря компрессии — регулировка зазоров на холодную по регламенту; Карбюратор: засорение жиклёров, плохой холостой, не работает автообогатитель (электроподсос) — чистка карбюратора, проверка электроподсоса (сопротивление ≈ 5–10 Ом, горячий при работе); Ремень вариатора изнашивается и рвётся — скутер перестаёт ехать — менять по пробегу (8–15 тыс. км) и по ширине, возить запасной; при замене — осмотр щёк вариатора.
