ZS PR300 · неисправность

Стучит мотор ZS PR300: BSE Z8, Kayo K1 300, Regulmoto Athlete 300 и другие

Проверка по шагам для мотора ZS PR300 (271.3 см³) — с его цифрами. Подходит для 19 моделей с этим мотором. Иди по порядку, от простого к сложному. Частые причины: коленвал / шатун, клапанный зазор, цепь ГРМ, детонация.

Цифры ZS PR300

СвечаNGK DR8EA (заводской мануал Kayo), зазор 0.65⁠–⁠0.75 мм
Клапаны (на холодную)впуск 0.10⁠–⁠0.15 мм по заводскому сервис-мануалу Kayo T4 300; 0.03 мм (в другой таблице — 0.01) по руководству Kayo по мотоциклам, выпуск 0.15⁠–⁠0.20 мм по сервис-мануалу T4 300; 0.05 мм (в другой таблице — 0.03) по руководству Kayo
Масло10W-40, API SJ, 1.0 л при замене, 1.1 л после разборки (Kayo T4 300, ZS175FMN)

Что проверить

  1. Где и как стучит?
    • Глухой снизу, усиливается с оборотами → Коленвал / шатун. Не заводи. Разборка и дефектовка.
    • Цоканье сверху на ХХ → Клапанный зазор. Регулировка: 0.10–0.15 мм по заводскому сервис-мануалу Kayo T4 300 / 0.15–0.20 мм по сервис-мануалу T4 300.
    • Лязг на сбросе газа → Цепь ГРМ. Цепь, натяжитель и успокоители комплектом.
    • Звон под нагрузкой в гору → Детонация. Бензин АИ-95, свеча NGK DR8EA, проверь бедность смеси.
    • Перестук поршня на холодную → Износ поршня. Замер зазора поршень–цилиндр.
