ZS1P62YML-2 глохнет на холодную: Sharmax Sport 190, Xmotos XB88 190

Проверка по шагам для мотора ZS1P62YML-2 (187.2 см³) — с его цифрами. Подходит для 2 моделей с этим мотором. Иди по порядку, от простого к сложному. Частые причины: проблема не в прогреве, не работает обогатитель, подсос воздуха, засор холостого канала.

Клапаны (на холодную)впуск 0.05⁠–⁠0.07 мм по руководству Daytona Anima 190F; 0.08 мм (0.003″) по Thumpstar, выпуск 0.05⁠–⁠0.07 мм по Daytona; 0.13 мм (0.005″) по Thumpstar
Масло10W-40, API SG и выше (Daytona), 0.60 л при замене, 0.65 л с фильтром, 0.70 л всего (Daytona; с маслорадиатором — больше); Thumpstar — 0.95 л. Доливай по смотровому окну

Компрессия11⁠–⁠13 бар

Что проверить

  1. После прогрева проблема пропадает?Нет → Проблема не в прогревеСмотри жиклёры: главный 118–128, холостой 40. Чистка карбюратора.
  2. Пусковой обогатитель (подсос) работает?Залип → Не работает обогатительПочисти шток, проверь трос и ход рычага.
  3. Обороты холостого плавают вверх-вниз?Да → Подсос воздухаПроверь впускной патрубок и хомуты: брызни WD на стыки на холостых — изменились обороты, значит там.
  4. Клапаны регулировал по регламенту (0.05–0.07 мм по руководству Daytona Anima 190F / 0.05–0.07 мм по Daytona)?Да → Засор холостого каналаПродуть холостой жиклёр 40, отрегулировать ХХ 1600–1800.Давно → Зажаты клапаныРегулировка на холодную: впуск 0.05–0.07 мм по руководству Daytona Anima 190F, выпуск 0.05–0.07 мм по Daytona.
