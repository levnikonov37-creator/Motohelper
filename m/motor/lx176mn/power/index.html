LX176MN не тянет: JHL H5 YBS300, JHL H6 YBS300, Motax EX 300 и другие

Проверка по шагам для мотора LX176MN (295 см³) — с его цифрами. Подходит для 4 моделей с этим мотором. Иди по порядку, от простого к сложному. Частые причины: бедно на малом газе, бедно на верхах, общее падение, буксует сцепление.

Цифры LX176MN

СвечаTORCH B8RC / NGK CR8E / DENSO U24ESR-N, зазор 0.7⁠–⁠0.8 мм
Клапаны (на холодную)впуск 0.10⁠–⁠0.20 мм (0.15 ± 0.05), выпуск 0.15⁠–⁠0.25 мм (0.20 ± 0.05)
Масло10W-40, API SJ и выше, JASO MA, 1.2 л при замене без фильтра, 1.3 л после разборки (Loncin YBS300)
Обороты ХХ1500⁠–⁠1700
Компрессия7⁠–⁠10 бар (700⁠–⁠1000 кПа при прокрутке > 1200 об/мин; предел — 6.5 бар)
КарбюраторNIBBI PWK34
Главный жиклёр140⁠–⁠150

Что проверить

  1. Когда пропадает тяга? Пик мотора — 29 л.с.
    • На низах, захлёбывается → Бедно на малом газе. Игла выше, холостой жиклёр 40–42, ХХ 1500–1700.
    • На верхах, не крутится → Бедно на верхах. Главный жиклёр больше 140–150. Проверь воздушный фильтр.
    • Везде, вяло → Общее падение. Компрессия 7–10 бар, клапаны, засор выпуска, тормоза не подклинивают?
    • Обороты растут, скорость нет → Буксует сцепление. Свободный ход рычага 10–15 мм, масло JASO MA.
