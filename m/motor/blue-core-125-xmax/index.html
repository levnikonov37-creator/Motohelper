Частые вопросы о Blue Core 125 (XMAX)

Какое масло заливать в мотор Blue Core 125 (XMAX)?

10W-30 / 10W-40 (JASO MB); в редуктор — 80W-90, объём ≈ 1.3 л (1.5 при разборке); редуктор ≈ 0.15 л. Замена каждые 4 000 км · ≈ 100 моточ.

Какая свеча стоит на Blue Core 125 (XMAX)?

NGK LMAR8A-9, зазор 0.8–0.9 мм.

Какие зазоры клапанов на Blue Core 125 (XMAX)?

Впуск 0.10–0.14 мм, выпуск 0.24–0.28 мм, на холодном моторе. Проверять каждые 12 000 км · ≈ 300 моточ.

Какой бензин заливать в Blue Core 125 (XMAX)?

АИ-92 / АИ-95.

На каких мотоциклах стоит Blue Core 125 (XMAX)?

Yamaha XMAX 125.

Какие слабые места у Blue Core 125 (XMAX)?

Ремень вариатора изнашивается и рвётся — скутер перестаёт ехать — менять по пробегу (8–15 тыс. км) и по ширине, возить запасной; при замене — осмотр щёк вариатора; Сцепление вариатора: колодки и колокол — дёргание при трогании, пробуксовка — колодки сцепления и пружины по износу, колокол — если есть ступенька/овал; Инжектор: грязная форсунка, слабый бензонасос, мотор не заводится на севшей АКБ — свежий бензин, фильтр насоса, заряженная АКБ; чистка форсунки.
