BSE Z10 перегревается

Проверка по шагам для мотора ZS174MN-5 (279.6 см³) — с его цифрами. Иди по порядку, от простого к сложному. Частые причины: мало масла, бедная смесь, охлаждение.

Цифры ZS174MN-5

СвечаNGK CR8EB (заводской мануал Kayo K5), зазор 0.7⁠–⁠0.8 мм
Клапаны (на холодную)впуск 0.02⁠–⁠0.04 мм (таблица заводского мануала Kayo K5; в разделе сборки того же мануала — 0.04⁠–⁠0.06), выпуск 0.02⁠–⁠0.04 мм (в разделе сборки — 0.04⁠–⁠0.06)
Масло10W-40, API SJ, 1.0 л при замене, 1.1 л первая заливка, максимум 1.2 л (Kayo K5, ZS174MN-5)
Обороты ХХ1400⁠–⁠1600 (1500 ± 100)
Компрессия12⁠–⁠14 бар
КарбюраторNIBBI PWK34
Главный жиклёр140⁠–⁠152

Что проверить

  1. Уровень масла в норме? Объём 1.0 л при замене, 1.1 л первая заливка, максимум 1.2 л (Kayo K5, ZS174MN-5)Мало → Мало маслаДолей до метки. Ищи утечки и сизый дым.
  2. Свеча светлая, белёсая?Да → Бедная смесьИгла выше, главный жиклёр больше 140–152.Нет → ОхлаждениеЖидкостное: воздушник — маслорадиатор; жидкостное — вентилятор, термостат, помпа.
