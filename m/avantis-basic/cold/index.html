Avantis Basic глохнет на холодную

Проверка по шагам для мотора 1P54FMI (124 см³) — с его цифрами. Иди по порядку, от простого к сложному. Частые причины: проблема не в прогреве, не работает обогатитель, подсос воздуха, засор холостого канала.

Цифры 1P54FMI

СвечаNGK C7HSA, зазор 0.6⁠–⁠0.8 мм
Клапаны (на холодную)впуск 0.05⁠–⁠0.07 мм по руководству Patron Junior 125; 0.08 мм по руководству Kayo по питбайкам, выпуск 0.05⁠–⁠0.07 мм по Patron; 0.09 мм по Kayo
МаслоSAE 10W-40, 0.9 л (Patron Junior 125)
Обороты ХХ1500⁠–⁠1700
Компрессия10⁠–⁠12 бар
КарбюраторPZ19 / PE22
Главный жиклёр90⁠–⁠100

Что проверить

  1. После прогрева проблема пропадает?Нет → Проблема не в прогревеСмотри жиклёры: главный 90–100, холостой 35–38. Чистка карбюратора.
  2. Пусковой обогатитель (подсос) работает?Залип → Не работает обогатительПочисти шток, проверь трос и ход рычага.
  3. Обороты холостого плавают вверх-вниз?Да → Подсос воздухаПроверь впускной патрубок и хомуты: брызни WD на стыки на холостых — изменились обороты, значит там.
  4. Клапаны регулировал по регламенту (0.05–0.07 мм по руководству Patron Junior 125 / 0.05–0.07 мм по Patron)?Да → Засор холостого каналаПродуть холостой жиклёр 35–38, отрегулировать ХХ 1500–1700.Давно → Зажаты клапаныРегулировка на холодную: впуск 0.05–0.07 мм по руководству Patron Junior 125, выпуск 0.05–0.07 мм по Patron.
