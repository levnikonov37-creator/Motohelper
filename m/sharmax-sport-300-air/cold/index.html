Sharmax Sport 300 Air глохнет на холодную

Проверка по шагам для мотора ZS PR300 (271.3 см³) — с его цифрами. Иди по порядку, от простого к сложному. Частые причины: проблема не в прогреве, не работает обогатитель, подсос воздуха, засор холостого канала.

Цифры ZS PR300

СвечаNGK DR8EA (заводской мануал Kayo), зазор 0.65⁠–⁠0.75 мм
Клапаны (на холодную)впуск 0.10⁠–⁠0.15 мм по заводскому сервис-мануалу Kayo T4 300; 0.03 мм (в другой таблице — 0.01) по руководству Kayo по мотоциклам, выпуск 0.15⁠–⁠0.20 мм по сервис-мануалу T4 300; 0.05 мм (в другой таблице — 0.03) по руководству Kayo
Масло10W-40, API SJ, 1.0 л при замене, 1.1 л после разборки (Kayo T4 300, ZS175FMN)
Обороты ХХ1260⁠–⁠1540 (1400 ± 10 %)
Компрессия11⁠–⁠13 бар
КарбюраторPE30 / PWK32⁠–⁠34
Главный жиклёр118⁠–⁠128

Что проверить

  1. После прогрева проблема пропадает?Нет → Проблема не в прогревеСмотри жиклёры: главный 118–128, холостой 40–42. Чистка карбюратора.
  2. Пусковой обогатитель (подсос) работает?Залип → Не работает обогатительПочисти шток, проверь трос и ход рычага.
  3. Обороты холостого плавают вверх-вниз?Да → Подсос воздухаПроверь впускной патрубок и хомуты: брызни WD на стыки на холостых — изменились обороты, значит там.
  4. Клапаны регулировал по регламенту (0.10–0.15 мм по заводскому сервис-мануалу Kayo T4 300; 0.03 мм (в другой таблице — 0.01) по руководству Kayo по мотоциклам / 0.15–0.20 мм по сервис-мануалу T4 300; 0.05 мм (в другой таблице — 0.03) по руководству Kayo)?Да → Засор холостого каналаПродуть холостой жиклёр 40–42, отрегулировать ХХ 1260–1540 (1400 ± 10 %).Давно → Зажаты клапаныРегулировка на холодную: впуск 0.10–0.15 мм по заводскому сервис-мануалу Kayo T4 300; 0.03 мм (в другой таблице — 0.01) по руководству Kayo по мотоциклам, выпуск 0.15–0.20 мм по сервис-мануалу T4 300; 0.05 мм (в другой таблице — 0.03) по руководству Kayo.
