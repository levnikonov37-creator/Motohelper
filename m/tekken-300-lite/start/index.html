Tekken 300 Lite не заводится

Проверка по шагам для мотора ZS PR300 (271.3 см³) — с его цифрами. Иди по порядку, от простого к сложному. Частые причины: нет подачи топлива, нет искры, залило свечу, подсос или фазы.

Цифры ZS PR300

СвечаNGK DR8EA (заводской мануал Kayo), зазор 0.65⁠–⁠0.75 мм
Клапаны (на холодную)впуск 0.10⁠–⁠0.15 мм по заводскому сервис-мануалу Kayo T4 300; 0.03 мм (в другой таблице — 0.01) по руководству Kayo по мотоциклам, выпуск 0.15⁠–⁠0.20 мм по сервис-мануалу T4 300; 0.05 мм (в другой таблице — 0.03) по руководству Kayo
Масло10W-40, API SJ, 1.0 л при замене, 1.1 л после разборки (Kayo T4 300, ZS175FMN)
Обороты ХХ1260⁠–⁠1540 (1400 ± 10 %)
Компрессия11⁠–⁠13 бар
КарбюраторPE30 / PWK32⁠–⁠34
Главный жиклёр118⁠–⁠128

Что проверить

  1. Отсоедини топливный шланг от карбюратора. Бензин идёт?Нет → Нет подачи топливаПроверь бензокран, сапун крышки бака, фильтр в шланге. На EFI — предохранитель и реле насоса.
  2. Выкрути свечу NGK DR8EA, прижми к массе и крутани. Есть синяя искра?Зазор свечи 0.65–0.75 мм.Нет → Нет искрыНовая свеча NGK DR8EA (0.65–0.75 мм). Затем колпачок, катушка, пикап, коммутатор. Проверь массу и кнопку стоп.
  3. Свеча после попыток мокрая и пахнет бензином?Да → Залило свечуВыкрути свечу, прокрути мотор с полным газом без свечи, просуши. Проверь игольчатый клапан поплавковой камеры.
  4. Компрессия в норме (11–13 бар)?Замер на прогретом моторе с полностью открытым газом.В норме → Подсос или фазыПроверь впускной патрубок, метки ГРМ, засор холостого жиклёра (40–42).Ниже → Низкая компрессияСначала клапаны: впуск 0.10–0.15 мм по заводскому сервис-мануалу Kayo T4 300, выпуск 0.15–0.20 мм по сервис-мануалу T4 300. Если зазоры в норме — износ ЦПГ.
