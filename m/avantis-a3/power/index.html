Avantis A3 не тянет

Проверка по шагам для мотора ZS174MN-3 (279.5 см³) — с его цифрами. Иди по порядку, от простого к сложному. Частые причины: бедно на малом газе, бедно на верхах, общее падение, буксует сцепление.

Цифры ZS174MN-3

СвечаNGK CR8EB (заводской мануал Zongshen), зазор 0.7⁠–⁠0.8 мм
Клапаны (на холодную)впуск 0.02⁠–⁠0.04 мм по заводскому мануалу Zongshen CBS300; 0.08 мм по руководству Avantis A6 — источники расходятся, выпуск 0.02⁠–⁠0.04 мм по заводскому мануалу Zongshen; 0.10 мм по руководству Avantis
Масло10W-40, API SJ и выше, 1.3 л (Zongshen ZS174MN-3)
Обороты ХХ1300⁠–⁠1500 (1400 ± 100)
Компрессия11⁠–⁠13 бар
КарбюраторNIBBI PE30 / PWK34
Главный жиклёр120⁠–⁠130

Что проверить

  1. Когда пропадает тяга? Пик мотора — 25 л.с.
    • На низах, захлёбывается → Бедно на малом газе. Игла выше, холостой жиклёр 40–42, ХХ 1300–1500.
    • На верхах, не крутится → Бедно на верхах. Главный жиклёр больше 120–130. Проверь воздушный фильтр.
    • Везде, вяло → Общее падение. Компрессия 11–13 бар, клапаны, засор выпуска, тормоза не подклинивают?
    • Обороты растут, скорость нет → Буксует сцепление. Свободный ход рычага 10–15 мм, масло JASO MA.
