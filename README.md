# MotoHelper

Справочник по китайским эндуро, питбайкам и мопедам (и не только): характеристики двигателя,
ТО по пробегу, диагностика «что сломалось», инструкции по ремонту, тюнинг и подбор запчастей.
Работает целиком в браузере: сервер нужен только для ИИ-механика.

## Как добавить модель или мотор

Всё делается в `js/data.js`. Новые записи добавляются в конец файла, перед строкой `sortBikes();`.
Правила кратко описаны в начале файла.

```js
// мотор: копия похожего с правками
CL("NB300X", "NB300", { code: "ZS174MN-X", name: "Zongshen NB300X", hp: 30 });

// модель с одним мотором (повтор марки и модели пропускается)
addBike("Kayo", "K6-R 300", "Эндуро", "NB300");
addBike("Kayo", "K7 300", "Эндуро", "NB300", { hp: 29, approx: true }); // approx → «≈» в интерфейсе

// сменить мотор у существующей модели
setEngine("Kayo", "T4 300", 0, "PR300");

// синонимы мотора для поиска (цифры с картера, русская раскладка) — в ENGINE_AKA
ENGINE_AKA["NB300"] = "174 174mn 174mn5 nb300 нб300";

// добавить поколение к существующей модели
addVersion("Honda", "CRF450X", "CRF450", "2019+", { hp: 50 });

// уточнить поля существующего мотора (по мануалу); code и cc так менять нельзя
fixE("NB300", { valveIn: "0.07 мм", valveEx: "0.08 мм" });

// модель сразу с поколениями
G("Suzuki", "Bandit 1200", "Нейкед", [["SUZ_GSF1200C", "1996–2000"], ["SUZ_GSF1200K1", "2001–2006"]]);

// поколения одной модели (старые сохранения пользователей переносятся сами)
mergeGenerations("Honda", "CRF450R", [["CRF450R 2002–2008", "2002–2008"], ["CRF450R 2009–2016", "2009–2016"]]);
```

Типы мотоциклов: Эндуро, Питбайк, Кросс-эндуро, Мотард, Тур-эндуро, Лёгкий эндуро, Мопед,
Спорт, Нейкед, Чоппер, Триал, Классика.

## Проверка

```bash
npm install          # один раз
npm test             # база + сайт в браузере
npm run test:data    # только база, без браузера, за секунду
```

- `tests/check-data.js` проверяет, что у каждой модели есть двигатель, нет дублей,
  у запчастей правильные привязки и что расчёты (обороты, ТО, жиклёры, максималка) идут без ошибок.
- `tests/check-page.js` открывает сайт в Chromium, ищет и выбирает мотоцикл, проходит по разделам, проверяет кнопку «Назад» и поиск по сайту,
  фото модели (вместо настоящих картинок — заглушка) и рисунок, если фото не загрузилось, и перенос старых сохранений.

На GitHub эта проверка запускается сама при каждом pull request и при изменениях в `main` (вкладка Actions).
Если она красная, в main это лучше не сливать.

## Фото мотоцикла

Вид «Мотоцикл» показывает настоящее фото выбранной модели:

1. у крупных марок (Honda, KTM, Yamaha и т.п.) — свободное фото с Wikimedia Commons, если там есть точное совпадение марки и модели;
2. иначе — первую картинку из поиска Bing по названию модели. Несколько запросов («мотоцикл», «эндуро», «motorcycle», год)
   дают несколько разных снимков: кнопка «Другое фото» листает их, выбор запоминается в браузере.

Картинки грузятся прямо с серверов Wikimedia и Bing и на сайте не хранятся. Нет сети или фото не загрузилось за 12 секунд —
показывается рисунок из `js/bike-art.js`. Своё фото мотоцикла добавляется на вкладке «Фото».

## Как обновлять сайт

Правки делаются в ветке и попадают в `main` через pull request, где сразу видно, что изменилось.
Если загружать файлы вручную через GitHub, загружай файл из нужной папки целиком (например, `js/data.js`).

## Сервер ИИ-механика

Код лежит в `worker/motohelper-ai.js`. Чтобы обновить сервер: Cloudflare → Workers & Pages → `motohelper-ai` →
Edit code → вставить файл целиком → Deploy. Ключи задаются в Settings → Variables and Secrets:

- `GEMINI_API_KEY` — ключ Google AI Studio; с ним ИИ смотрит фото;
- `GROQ_API_KEY` — необязательно, запасной вариант для текста;
- привязка Workers AI с именем `AI` — необязательно, последний запасной вариант.

Сайт сам узнаёт, что сервер принимает фото (GET на адрес сервера отвечает `{"images": true}`), и показывает кнопку фото.

### Сообщения «Нашёл неточность»

Кнопка внизу обзора мотоцикла отправляет сообщение на тот же сервер ИИ-механика. Чтобы сообщения сохранялись:

1. Cloudflare → Storage & Databases → KV → Create namespace (например, `motohelper-feedback`);
2. в воркере `motohelper-ai` → Settings → Bindings → Add → KV namespace, имя привязки `FEEDBACK`;
3. Settings → Variables and Secrets → секрет `FEEDBACK_TOKEN` — любой длинный пароль;
4. обновить код воркера из `worker/motohelper-ai.js` и нажать Deploy.

Прочитать сообщения: открыть `<адрес воркера>/?feedback=1&token=<FEEDBACK_TOKEN>`. Сообщения хранятся год.
Если сервер не настроен, сайт предложит пользователю скопировать текст.
