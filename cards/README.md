# Карточки для маркетплейсов

Инструменты для работы «делаю карточки мотозапчастей на WB/Ozon». К сайту MotoHelper отношения не имеют.

**Не мержить в main:** main публикуется через GitHub Pages, всё оттуда станет доступно по ссылке.
Списки продавцов (`out/`) в git не попадают — там ИНН и почты.

| Файл | Что внутри |
|---|---|
| `TREBOVANIYA.md` | Требования WB / Ozon / Яндекс Маркета к фото и инфографике, порядок слайдов |
| `SOOBSHCHENIE.md` | Как писать продавцам: каналы, первое сообщение, ответы на возражения, цены |
| `leads.py` | Поиск продавцов со слабыми карточками |
| `wb.py` | Чтение карточек WB с их CDN |
| `data/` | Собранные списки артикулов |

## Поиск продавцов

```bash
python3 cards/leads.py cards/data/articles-2026-10-30.txt -o cards/out
```

На входе — любой текст со ссылками на товары WB или артикулами (можно просто скопировать
адреса карточек из поиска WB в файл). На выходе в `cards/out`:

- `leads.csv` — российские продавцы, самые слабые сверху, с готовым первым сообщением;
- `cards.csv` — каждая карточка и что с ней не так;
- `report.html` — то же с главными фото. Перед тем как писать продавцу, посмотри его карточку глазами.

Баллы слабости: 1–3 фото +3, нет совместимости в характеристиках +3, главное фото на белом
без оформления +3, описание короче 300 знаков +2, 4–5 фото +1, меньше 5 характеристик +1, нет видео +1.

Поиск самого WB (search.wb.ru) из облака закрыт (403), поэтому артикулы собираются через
поисковики или вручную. С домашнего компьютера в России поиск WB открывается — это следующий шаг автоматизации.
